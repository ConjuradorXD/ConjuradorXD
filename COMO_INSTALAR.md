# Como instalar

1. Crie um repositório **público** com o nome EXATO do seu usuário do GitHub.
2. Coloque `README.md` na raiz.
3. Coloque a pasta `assets` junto do README.
4. Troque `ConjuradorXD` no README se seu username for diferente.
5. Faça commit e abra seu perfil.

Estrutura:

```text
README.md
assets/
  banner.svg
  divider.svg
  footer.svg
  pixel-sword.svg
  pixel-potion.svg
  pixel-gem.svg
```

O layout já está preparado para receber uma animação. Para transformar o banner em GIF, substitua `./assets/banner.svg` por `./assets/banner.gif` e coloque o GIF na pasta `assets`.
